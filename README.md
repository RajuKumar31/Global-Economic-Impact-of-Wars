# 🌍 Global Economic Impact of Wars – Power BI Dashboard

## 📊 Project Overview

This project analyzes the economic impact of global conflicts using an interactive Power BI dashboard built on a dataset of over 100,000 records.

The analysis focuses on key economic indicators such as GDP change, inflation, unemployment, and poverty to understand how wars affect economies.

---

## 🎯 Objective

To quantify and analyze the economic damage caused by conflicts and identify key drivers of economic disruption.

---

## 🧠 Key Features

* Developed a custom **Economic Impact Score** using weighted metrics
* Scatter plot analysis (Inflation vs GDP contraction)
* War intensity vs economic damage analysis
* Decomposition Tree with AI split for root cause analysis
* Trend analysis over time
* Sector-wise impact ranking

---

## 📈 Key Insights

* High inflation combined with GDP decline leads to the most severe economic impact
* War intensity alone does not determine economic damage
* Economic impact is concentrated in specific regions
* Manufacturing and energy sectors are most affected
* Economic impact of conflicts has increased over time
